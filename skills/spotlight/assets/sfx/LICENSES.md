# Sound-effect licences

Every effect is CC0 (Creative Commons Zero 1.0, a public-domain dedication). No attribution is required; the authors are listed as a courtesy. All files were retrieved on 2026-10-12.

Processing applied to every file:
- leading silence below −60 dBFS trimmed (each file now has under 1 ms of lead-in);
- trailing silence below −70 dBFS trimmed;
- a short fade-out (15 ms by default, 30–150 ms where noted) and a 1 ms fade-in;
- resampled to 48 kHz;
- a static gain only where the decoded peak would have exceeded −1 dBFS;
- encoded as Ogg Vorbis q5, with the source's channel count kept.

Whooshes were also high-passed at 100 Hz so they don't rumble.

For the Kenney packs, the page licence is quoted from the pack's own page, and the pack's bundled `License.txt` is quoted as well.
